# Contributing

NX9 is free to use but not open source, so this repository does not take code.  Here is how you can help.

## Report a bug

[Open a bug report](https://github.com/functional-dev/nx9-releases/issues/new?template=bug_report.yml).  The most useful reports include:

- the NX9 version (click the logo in NX9) and your macOS version,
- what you did, what you expected, and what happened instead,
- a screenshot, with anything private covered.

Search the [open issues](https://github.com/functional-dev/nx9-releases/issues) first;  adding detail to an existing report helps more than a duplicate.

## Suggest a feature

[Open a feature request](https://github.com/functional-dev/nx9-releases/issues/new?template=feature_request.yml) that describes the problem you want solved.  What you were trying to do tells us more than a proposed design.

## Improve the documentation

If something in the README or the release notes is wrong or unclear, open an issue that quotes it and says what would be clearer.

## Security problems

Please report these privately.  See [SECURITY.md](SECURITY.md).
